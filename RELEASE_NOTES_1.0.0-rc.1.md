# SpectralShipGen v1.0.0-rc.1

SpectralShipGen is an SFML-independent C++17 library for deterministic native-resolution pixel-art spaceship generation and animation. `v1.0.0-rc.1` is the first public release candidate and the start of the 1.0 compatibility epoch.

## Highlights

- deterministic native-resolution ship generation from explicit configuration and seed state;
- six built-in structural presets and six built-in faction presets;
- first-class custom structural/faction/palette profiles;
- portable recipe serialization and selective deterministic rerolls;
- IDLE, movement, and FIRE animation generation;
- reusable diagnostics/statistics backend;
- installable CMake package plus focused public examples.

## Compatibility

The numeric CMake/package version is `1.0.0`; `rc.1` is release-tag metadata. SpectralShipGen and SpectralShipGen Studio use independent Semantic Versioning after their coordinated initial 1.0 release.

Recipe schema v6 and diagnostics schema v2 are the 1.0 baselines. Pre-1.0 development formats are intentionally unsupported. See [`COMPATIBILITY.md`](COMPATIBILITY.md) for the complete source-API, CMake, recipe, deprecation, and deterministic-output policies.

Exact generated pixels are guaranteed for the same validated semantic input and deterministic seed state only when using the **same exact Library release revision**. Cross-release pixel identity is not automatically guaranteed.

## Generated output

Images, spritesheets, animation frames, and other output generated by SpectralShipGen may be used for any purpose, including commercial use, with no attribution requirement. The zlib license governs the software source, not generated output.

## Known limitations

- Binary ABI/C++ object layout is not promised stable across releases; rebuild consumers against the Library version they ship.
- Cross-release pixel identity is not guaranteed even when recipe readability remains compatible.
- Pre-1.0 recipe and diagnostics development schemas are intentionally unsupported.

## Studio

The coordinated Studio RC is **SpectralShipGen Studio v1.0.0-rc.1**, validated against this exact Library RC revision. Studio has its own independent version lifecycle after 1.0.
